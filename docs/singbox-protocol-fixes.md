# Исправления протоколов и интеграции sing-box

Ветка: `fix/singbox-protocol-audit`.
Основа: `0b98c1c9f02f125d856cc34d5a5ff4f399160289`.
Для проверки структуры параметров использованы исходники sing-box v1.14.0
(`0b8995879f29a9b98ee027bc17b75e101445b238`).

## Что изменено

- Импорт ссылок: однократное декодирование паролей и fragment, проверка портов,
  IPv6, Hysteria2 user:password и insecure, VMess alterId, идентификация
  Shadowsocks с учётом параметров транспорта.
- Inbound: перенос HTTP/SOCKS accounts, проверка структуры credentials,
  исключение отключённых пользователей, VMess alterId, Trojan fallback,
  совместимые TLS/REALITY, gRPC и socket-параметры. Настройки sniffing
  сохраняются при применении native-шаблона.
- Outbound: VLESS packetEncoding=none, proxySettings.tag/detour, Hysteria
  finalmask с обфускацией и port hopping, совместимые QUIC-параметры,
  TUIC inline-сертификаты и ALPN в подписках.
- Маршрутизация и DNS: порядок resolve для IPOnDemand, prefix-селекторы
  балансировщиков, default outbound, сохранение query в DoH URL,
  DNS с портом без схемы, evaluate/respond для нескольких DNS-серверов,
  сохранение DNS-правил при добавлении hosts, наследование выбранного DNS
  резолвера вместо принудительного local.
- Применение конфигурации: запись во временный файл, проверка будущим
  вызовом sing-box check перед заменой, сериализация операций сервиса,
  идентификация процесса по бинарнику и конфигурации, обнаружение раннего
  завершения, сохранение применённой конфигурации для egress.
- Обновление ядра: резервная копия бинарника, libcronet и конфигурации;
  восстановление прежней установки и процесса при ошибке обновления.
- Clash API и учёт: исключение закрытых сессий из online/count,
  обработка ошибок отключения, увеличение лимита ответа connections,
  начальный интервал Naive, сброс baseline при старте ядра,
  отмена коротких gRPC streams, отключение Clash listener у probe-процесса.
- Подписки: endpoint override для ShadowTLS, geodata в отдельных native
  профилях, проверка уникальности Hiddify tags, исключение отключённых
  клиентов из определения доступных форматов.

## Явные ограничения совместимости

Некоторые Xray-настройки нельзя корректно перенести в выбранную схему
sing-box. Вместо молчаливой потери их смысла возвращается ошибка. Это
касается, в частности, XHTTP, TCP HTTP headers, неподдерживаемых SIP002
plugins, encrypted VLESS и его fallbacks, неподдерживаемых TLS/REALITY и
sockopt полей, UDP=false для mixed/SOCKS, Freedom redirect/fragment/noises,
IPIfNonMatch и динамических Xray-балансировщиков с несколькими целями.
Для этих сценариев требуется native-конфигурация или отдельная реализация;
новая ветка не добавляет отсутствующие возможности самого ядра.

## Проверки и незакрытые вопросы

По указанию пользователя тесты и сборка не запускались. Выполнены просмотр
исходников, форматирование изменённых Go-файлов и git diff --check.
Добавленный вызов sing-box check выполняется при последующем применении
конфигурации пользователем; в рамках этой работы ядро не запускалось.
Успешная компиляция и работоспособность на сервере пока не подтверждены.

Исходные 100 пунктов аудита включали отдельные сценарии одних и тех же
дефектов и неподтверждённые кандидаты. Эта ветка не означает 100 независимых
подтверждённых и исправленных ошибок. Остаются вопросы, требующие проверки:

- Последние байты Naive-сессии, исчезнувшей между опросами Clash API,
  нельзя восстановить из уже отсутствующей записи connections.
- Полнота закрытой истории и счётчиков при большой нагрузке требует
  проверки протокола API и поведения ядра.
- DNS resolver для адреса proxy использует выбранный сервер непосредственно;
  это не воспроизводит весь набор DNS routing/hosts/fallback правил Xray.
- Формат Hiddify с единственным WireGuard endpoint требует подтверждения
  контрактом соответствующего клиента.
- Проверка раннего выхода процесса не заменяет полную проверку готовности
  всех listener и внешних соединений. Применение конфигурации не является
  переключением без перерыва в обслуживании.

Перед слиянием нужны отдельный запуск тестов, сборка с версией Go из go.mod
и проверка конфигураций установленной версией sing-box.
