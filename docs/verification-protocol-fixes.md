# Проверка исправлений протоколов и sing-box

Дата: 2026-10-04. Ветка: `fix/singbox-protocol-audit`.

## Исправления по результатам проверок

- Устранена регрессия генерации sing-box-подписок: стандартный неиспользуемый `dns.tag` больше не блокирует подписки. Маршрутизация по виртуальным DNS-тегам по-прежнему отклоняется, поскольку её нельзя перенести без изменения политики. Проверка применяется и к серверному конфигу, и к подпискам.
- Исправлена компиляция тестов импорта ссылок после удаления `defaultPort`; проверяются допустимые и недопустимые значения портов.
- Обновлены ожидания для однократного декодирования URL-фрагментов и явного отказа от неподдерживаемых Shadowsocks-плагинов.
- Исправлены ожидания TUIC: пустой пароль допустим при корректном UUID, порте и TLS.
- Обновлены проверки наследования DNS-резолвера и полного сертификатного fingerprint в Clash.
- Добавлена проверка отказа от преобразования динамической балансировки в статический selector.
- Исправлен процессный fixture: тестовый бинарник запускается с настоящей формой `run -c <config>`, вместо `/bin/sleep` без конфигурации.
- Проверки локальности Clash API теперь имеют детерминированные случаи для локального адреса, удалённого адреса и ошибки чтения интерфейсов. В рабочем коде сохраняется реальная проверка интерфейсов и отказ при ошибке.
- Обновлена проверка необходимости пользователей Shadowsocks.
- Исправлен тест ошибки выделения приоритета подписки: ошибки `Scan` инъецируются через GORM Row callback, ошибки выборки префикса — через Query callback.

## Ограничения проверки

Браузерный проект Storybook не исполнился: Playwright не нашёл Chromium, а `npx playwright install chromium` завершился ошибкой повреждённого ZIP-архива. Успешная сборка Storybook не заменяет браузерные тесты.

Интеграционные Go-тесты с PostgreSQL и внешними ядрами требуют настроенных подключений и бинарников. Тесты чтения реальных сетевых интерфейсов и идентификации процессов пропускаются при недоступности этих возможностей в среде. Отказы безопасности рабочего кода сохранены; детерминированные тесты контроля адресов выполняются.

Не проверялись реальные сетевые рукопожатия всех протоколов с внешними клиентами и ядрами. Результаты относятся к выполненным тестам и сборкам, а не ко всем возможным конфигурациям.
